旨在提供一个源码阅读辅助插件，保持代码整洁实现边阅读边做笔记但是对源码无侵入的帮助工具。视频介绍-[BiliBili](https://www.bilibili.com/video/BV1F47JzEEbz/)。

It is a help you reading source code plugin, to keep the code tidy, and to realize the help tool for reading and taking notes without intrusion into the source code. Video introduction - -[BiliBili](https://www.bilibili.com/video/BV1F47JzEEbz/).



# 功能(Function)
1. 仅在编辑器中嵌入标记和提示，保持代码整洁（不会在代码中添加注释）
Only in editor inlay tip, not add code
2. 支持IDEA内置书签，并且增加编辑功能
Extension idea bookmark
3. 在研读大型项目源码、梳理AI项目执行流程、剖析三方库代码等场景下非常适用
Using AI, reading code scenarios
4. 支持多端快速同步,不同设备之间快速数据共享
Share data for more computer
5. 支持快速跳转：从书签跳转到编辑器/从编辑器跳转到书签
jump from bookmark to editor/jump from editor to bookmark
